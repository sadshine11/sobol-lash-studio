# СОБОЛЬ — сайт студии наращивания ресниц

Одностраничный сайт без CMS и админки. Вся страница — один файл `index.html`:
разметка, стили и скрипты внутри него. Сборка не нужна, фреймворков нет.

```
index.html          вся страница
assets/img/         30 изображений (.webp)
assets/video/       3 видео (.mp4)
assets/fonts/       шрифты Prata и Golos Text (свои файлы, не с чужого CDN)
assets/favicon.svg  значок вкладки
tools/              служебные скрипты, которыми сделаны заглушки; на сайт не влияют
```

## Что сейчас заглушки

Фото, видео, тексты, отзывы, адрес и телефон — **демонстрационные**. Всё это
заменяется на ваше; ниже написано, где именно. Пока стоят заглушки, в
`index.html` включены две вещи, которые нужно убрать перед запуском:

1. `<meta name="robots" content="noindex, nofollow">` в начале файла — закрывает
   демо от поисковиков.
2. Строка «Демонстрационная версия…» в подвале.

## Как подставить свои материалы

### Фото

Положите свои `.webp` в `assets/img/` **под теми же именами** — менять разметку
не придётся:

| Файл | Где стоит | Пропорции |
| --- | --- | --- |
| `hero.webp` | первый экран | вертикальное, 4:5 |
| `effect-classic / wet / 15d / 2d / 3d.webp` | каталог эффектов | вертикальные, 4:5 |
| `work-01 … work-13.webp` | лента работ | 4:5, каждое третье — горизонтальное 3:2 |
| `video-01…03-poster.webp` | обложки видео | вертикальные, 9:16 |
| `about.webp` | блок «Обо мне» | вертикальное, 4:5 |
| `studio-01.webp` | блок «Где находимся» | горизонтальное, 3:2 |
| `slots-bg.webp` | подложка блока «Свободные окна» | горизонтальное |
| `diff-01…03.webp` | блок «Чем отличаемся» | квадратные |
| `og.webp` | картинка при отправке ссылки в мессенджер | 1200×630 |

Размер кадра подгоняется автоматически (`object-fit: cover`), но лучше сразу
давать нужные пропорции — так ничего важного не обрежется.

Для блока «Свободные окна» нужен кадр **с контрастом** (лицо, лампа, тёмные
ресницы). Поверх него лежит полупрозрачное стекло: если фото ровное и светлое,
размытие будет не видно и блок станет просто бежевым прямоугольником.

### Видео

`assets/video/work-01.mp4`, `work-02.mp4`, `work-03.mp4`. Вертикальные, без
звука, 5–10 секунд. Они запускаются сами, когда попадают на экран, и ставятся на
паузу, когда уходят. У каждого есть кнопка паузы, и при системной настройке
«уменьшить движение» автозапуск отключается.

### Логотип

Сейчас логотип набран шрифтом. Чтобы поставить картинку, замените в шапке:

```html
<span class="logo__mark">СОБОЛЬ</span>
```

на `<img src="assets/logo.svg" alt="СОБОЛЬ" height="24">`.

## Где править тексты

Всё правится прямо в `index.html` — ищите по заголовку секции, они подписаны
комментариями вида `<!-- ====== КАТАЛОГ ЭФФЕКТОВ ====== -->`.

**Телефон и первое сообщение** — в одном месте, в скрипте внизу файла:

```js
var PHONE = '79000000000';
var HELLO = 'Здравствуйте! Хочу записаться на наращивание ресниц.';
```

Все кнопки «Записаться» ведут в WhatsApp с этим текстом. Кнопки в каталоге
подставляют название эффекта сами (атрибут `data-msg`). Telegram и ВКонтакте
прописаны ссылками в блоке «Обо мне» и в подвале.

**Цены и описания эффектов** — блок `id="fx"`: пять панелей, в каждой цена,
описание, таблица и схема. Схемы (сколько волосков на одной реснице) нарисованы
кодом, их трогать не нужно.

**Свободные окна** — список `id="slots"`. Время пишется руками, а подпись под ним
(«завтра», «ср, 23 сен.») считается от сегодняшнего дня по атрибуту `data-day`:

```html
<li class="chip" data-day="1"><b>11:00</b><span>завтра</span></li>
```

`data-day="1"` — завтра, `"2"` — послезавтра, дальше подставится день недели с
датой. Так демо не устаревает, даже если его долго не открывать.

**Отзывы** — карточки `class="rv"`. Полный текст лежит в атрибуте `data-full`,
абзацы разделяются переводом строки. В карточке показывается начало, кнопка
«Читать полностью» появляется сама, только если текст не поместился.

**Вопросы** — теги `<details>`, первый открыт по умолчанию.

## Проверить локально

```bash
node tools/serve.mjs
```

Откроется на `http://localhost:5173`. Просто открыть `index.html` двойным
щелчком тоже можно, но из файла браузер не подгрузит шрифты — поэтому лучше
через сервер.

## Что заложено внутри

- **Адаптив**: на телефоне одна узкая колонка, на десктопе — сетка с полем для
  подписи слева. Проверено от 320 px.
- **Ленты** (работы, отзывы) листаются пальцем, колесом, перетаскиванием мышью,
  стрелками на десктопе и с клавиатуры.
- **Доступность**: переходы по табу с видимой рамкой, вкладки каталога
  переключаются стрелками, окно отзыва закрывается по Escape и возвращает фокус,
  контраст текста проверен (минимум 4,6 : 1).
- **Уменьшенное движение**: при системной настройке все анимации и автозапуск
  видео выключаются.
- **Скорость**: шрифты свои и урезаны до нужных символов (63 КБ на оба
  начертания вместо ~200 КБ), картинки в WebP с `loading="lazy"`, видео
  подгружаются только когда нужны.

## Шрифты

Prata (заголовки) и Golos Text (текст) — открытые лицензии SIL OFL. Файлы в
`assets/fonts/` урезаны до латиницы, кириллицы и нужной пунктуации. Если
добавите в тексты редкий символ и он покажется чужим шрифтом — значит, его нет в
наборе; пересобрать можно скриптом `tools/fonts3.mjs`.
